# Attribution — public source photos of the eval

Two kinds of files live in this directory. Licence of each Commons file read from the Wikimedia Commons API (`extmetadata`) on 2026-10-21 and re-checkable with `python eval/check_commons.py --download` (compares licence and bytes with Commons). The files are the unmodified 1280 px thumbnails Commons serves for each original.

The synthetic eval cases (`python eval/build_set.py`, not committed) are derivatives of these photos: blurred, darkened, rotated, warped, mirrored, re-encoded copies, some with a drawn block pasted in. Derivatives of CC BY-SA files are shared under the same CC BY-SA licence (see LICENSE-NOTE.md). No endorsement by any author is implied.

## Mikhail Oskola's own video (frames)

`own-sink-video/f*.jpg` and `own-sink-video/clip-31s-36s.mp4`: frames of a phone video Mikhail Oskola shot under his own kitchen sink on 2026-10-20 while looking for a leak. © Mikhail Oskola; published in this repository with his consent (2026-10-21T11:38:30Z) for the StepSpotter evaluation. The source .MOV is not in the repository (its metadata carries location); frames were decoded and re-written by OpenCV with no metadata (`eval/extract_video.py`). Each kept frame was looked at: no people, faces, reflections, addresses or mail.
